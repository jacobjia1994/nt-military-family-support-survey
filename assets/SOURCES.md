Retrieved 24 September 2026 for the Lutheran Care questionnaire design requested by the project contributor. Lutheran Care retains its brand rights.

- Colour and type references: Lutheran Care website child CSS https://www.lutherancare.org.au/wp-content/themes/enacare-child/style.css and base CSS https://www.lutherancare.org.au/wp-content/themes/enacare/assets/css/enacare-core.css . These are observed website styles, not a supplied brand manual. The action colour is darkened to #B94626 for legibility with white button text.

No external font service or tracking script is loaded by this questionnaire.
